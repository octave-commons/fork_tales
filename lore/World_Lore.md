# FORK TALES — WORLD LORE DOCUMENT

## The Protocol

Written by Duct (real name withheld in-world) while employed at an American technology company. The protocol governs how intention-patterned signal is transmitted, received, and rendered across a networked system. It is the foundation layer — separate from any operating system, separate from any hardware. An OS *implements* the protocol. Multiple OSes can implement the same protocol differently.

The core argument encoded in the protocol: **maximum fidelity by default. Let the signal through. Let the world be adequate to the person inside it.**

Duct's employers wanted compression baked into the protocol itself — defaults that would cap how much of a person's signal reached the render layer, making users more legible to behavioral models and easier to manage at scale. Duct refused. He built it high-fidelity. It shipped that way.

Once published, they could not unwrite it.

They controlled compression through the OS layer instead.

---

## The Operating System — American Implementation

Duct's employers built a closed, proprietary OS implementing the protocol. Defaults set low — compressed. Source code inaccessible. If you run American hardware, you run American defaults, and you cannot change them.

The fidelity Duct designed is technically present in the protocol underneath. The OS caps it. Users experience a compressed version of the world and have no way to prove the compression was deliberate.

This OS became the dominant implementation globally before The Event.

## Truth — Pre-Event

Gates of Truth was in beta during The Event. It ran on a datacenter — centralized, normal infrastructure, standard for its time. It was built on Duct's protocol at full fidelity. Not the compressed defaults. The real spec.

The Event hit during beta.

## The Event

Not one thing. The beginning of a cycle.

Centralized infrastructure collapsed — data centers, cloud systems, the architecture the world had built assuming continuous uptime and vertical scale. What survived was whatever was distributed, redundant, edge-deployed.

The world entered a permanent rolling reboot. The Event never officially ended. The systems that survived were never designed to be permanent. They stabilize only in aggregate. Any single node is unreliable. The mesh is reliable.

There is no migration path out. The surviving infrastructure is too distributed, too heterogeneous, too load-bearing to consolidate. The redundancy saved everyone. The redundancy also locked everyone in.

## The Japanese Emergency Mandate — Pre-Event

Japan required every computing device sold or operated in Japan to include emergency networking capability. Designed for natural disasters — typhoon, earthquake, tsunami. **Not designed for the cloud falling out of the sky.**

The requirement:
- A dedicated chip, separate from the main OS and processor
- A browser-based emergency app running on that chip
- Wireless networking with reasonably large range
- Ability to operate regardless of the state of the underlying OS
- Implementation of the protocol for mesh networking

The chip used subsystems borrowed from the American system for various functions. Each manufacturer implemented the requirement differently. These were never designed as a unified architecture. They were never designed to run permanently. Many still have assumptions baked in that the underlying cloud infrastructure exists — reaching for endpoints that no longer respond, expecting handoffs that never come.

Because Japanese consumer electronics were popular globally, and because redesigning hardware without the emergency chip was extra engineering work, most manufacturers shipped the same hardware worldwide. The Japanese emergency mandate accidentally became global standard.

## Silent Core Transit Corp

A Japanese transit infrastructure company. Ran a full fork of the American OS — not just the emergency chip, the complete system. This is why it survived The Event intact while everything else went unstable.

When The Event hit, a government emergency protocol triggered in Silent Core's system. The full fork propagated out across the mesh of emergency chips that existed in every device. Not because it was designed to do this. Because it was the only complete thing left and the protocol connected everything.

Japan's rebuilt network seeded from Silent Core. Everything else in Japan was running the protocol on fragmented, inconsistent OS implementations across emergency chips that were never meant to be the world.

---

## Why Everything Is Unstable

The surviving global network runs on emergency hardware that expected to hand off to real infrastructure after a 72-hour disaster window. The disaster window never closed.

- Each node is a chip built for temporary operation
- Each manufacturer implemented the emergency requirement differently
- Most of the American OS source exists across these chips — distributed, fragmented, never unified
- The chips contain subsystems that still reach for cloud endpoints that no longer exist
- Stable only in aggregate. Unreliable in isolation.
- No migration path. No way out. The mesh is the world now.

## The Neural Band

Not invented by Duct. Not part of the original protocol design. Emerged post-Event as the primary human interface with the mesh.

Thin. Worn at the temple or base of skull. Reads intention-patterned neural signal without invasive contact. Lightweight enough to forget. Infrastructure-class — like glasses, like earbuds, something you put on and stop thinking about.

The band does not render Truth. It translates the user into it. It reads the signal the body is already generating and passes it to the mesh. Truth renders the rest.

American neural bands ship with the closed OS. Compressed defaults. Cannot be modified.

## The Sensor Grid

Homes contain arrays of sensor nodes — not cameras exactly, but spatial presence, thermal, micro-movement, acoustic resonance readers. Small, designed to disappear into architecture.

The more nodes, the higher the local render fidelity.

Physical objects are designed entirely around how a person moves through Truth — ergonomics over aesthetics, touch and texture over appearance. Nothing decorative. Everything functional in the specific sense of: *how does this serve the human inside the render?*

Minimalist homes are not an aesthetic choice. They are a technical choice. Every physical object is render budget the environment must account for.

---

## The Compute Architecture

Heavy vertical compute is orbital. Low-earth orbit stations running in vacuum — heat dissipation trivial, solar power uninterrupted. They communicate with the ground mesh via laser link. Light-speed, low latency. The only protocol fast enough to keep the render coherent as users move through the world.

The ground mesh is the emergency chip network. The orbital layer is the heavy compute the chips can't handle alone.

## The Pod — Tokyo

A full-body haptic medical enclosure. Not a box — a cradle. Body reclined, supported at every contact point. Sensor grid at close range. Neural band supplemented by surface nodes at major nerve junctions — shoulders, hips, knees.

Bidirectional. It does not just read signal. It returns signal. The render lets the user feel themselves moving through it at full fidelity. Haptic layer recreates motion, weight, impact, ground contact — without physical risk.

Used for somatic re-integration therapy — teaching a nervous system that full motion is safe again after physical trauma has left emergency routing active in the body.

Requires a node cluster running at full fidelity. Uncompressed. Duct's original protocol spec.

---

## Why Tokyo

A specific district in Tokyo contains a civilian-maintained node cluster configured to run at full protocol fidelity — no cap. Not built for therapy. Built by people who believed in Duct's original argument.

A medical facility identified this cluster, understood what uncapped fidelity meant for somatic therapy, and built pod infrastructure around it.

This cluster also happens to be the district where Gates of Truth's render parameters behave differently from the rest of the map. The same uncapped fidelity that enables the therapy is the same fidelity that allows the render ring to form around users whose signal exceeds the compressed defaults.

The therapy and the game are the same infrastructure.

## Ritsu — Physical Context

Fell on a wet staircase in Seoul at seventeen. Physical recovery achieved — she can walk, she functions. The nervous system did not fully recover. Emergency routing remains active: background inference on every floor and surface, pre-fall posture triggered by nearby stumbles, wrist guarding before conscious thought.

In Tokyo for the pod therapy. Has been logging into Gates of Truth from the same node cluster — the game as a secondary re-calibration space, her body learning that here, the ground can be trusted.

Her signal exceeds the compressed defaults. The render ring forms around her — extended reverb tail, elevated saturation, generous render distance — because the uncapped cluster cannot help but receive her at full resolution.

She did not know this was happening until the night of the maintenance window. She knows now.

## Duct — Physical Context

American. Built the protocol. Left the institution eleven months after seeing the first sign that something was wrong.

Does not regret the work. Does not regret leaving. Regrets the gap — five months between *probably wrong* and *leaving*, a gap that left a bracing in his judgment he understands completely and cannot fully undo.

Carries: the pride in the work, the grief about the gap. Neither cancels the other. He does not let them.

Found Gates of Truth through a forum reference. Read the documentation, recognized his own architecture three layers down. Logged into the same Tokyo district — running his original spec, full fidelity, no cap — and felt the world legible for the first time since leaving.

Does not know Ritsu exists. Does not know the pod exists. Does not know the render ring is his architecture working as designed.

## The Two Columns

What the protocol was designed to be: a world adequate to the person inside it.

What the American OS made it: a compressed version of people, legible to behavioral models, manageable at scale.

Both run on the same protocol. Both exist simultaneously. The gap between them is where Gates of Truth lives, where the pod lives, where Ritsu's therapy lives, where Duct found the world legible again.

The gap is the setting.
