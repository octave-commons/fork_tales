This draft intentionally narrows the paper boundary. The larger \texttt{fork\_tales} repository contains additional ideas about entity ecologies, narrative framing, graph instrumentation, and world simulation. Those ideas may deserve their own papers or companion artifacts, but carrying all of them into one systems paper would blur the main contribution.

The system also carries implementation risk. The formal model is richer than the currently cleaned implementation boundary, and some parts of the evaluation remain planned rather than finished. In particular, the paper will need to be careful about distinguishing conceptual formalization from experimentally validated behavior.

Another limitation is comparison scope. The runtime overlaps with graph RAG, temporal graph memory, and agent-memory architectures, but it is not reducible to any one of those categories. The related-work section will need to explain both the overlap and the difference cleanly so the paper is not misread as simply another memory-augmented RAG system. Finally, the decomposition itself remains part of the story. The eventual paper must be explicit about which claims are inherited from the source prototype and which are validated in the cleaned descendant surfaces.
