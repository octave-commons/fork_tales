Recent work on long-term language-agent memory has converged on a useful taxonomy: episodic traces, semantic memory, procedural rules, and retrieval or control mechanisms layered around them. CoALA provides one of the cleanest high-level cognitive framings, while MemGPT treats long-context management as a systems problem closer to operating-system memory than to plain prompt stuffing \citep{sumers2023coala,packer2023memgpt}.

Active retrieval work pushes in a related direction. Self-RAG and CRAG make retrieval a controlled loop rather than a one-shot preprocessing step, which is an important step beyond passive prompt hydration \citep{selfrag2023,crag2024}. GraphRAG and later graph-native memory systems then show that relational structure and multi-hop traversal matter for more than just local semantic lookup \citep{edge2024graphrag,hipporag2024,rasmussen2025zep}.

The system proposed here overlaps with all of those lines of work, but it differs in one important respect: graph structure, provenance, control packets, and resource pressure all live in the same runtime substrate. In most existing systems, resource budgeting and transport remain implementation details. Here they are first-class parts of the model. That is why this paper is better understood as a runtime paper than as another memory-augmented RAG design.
