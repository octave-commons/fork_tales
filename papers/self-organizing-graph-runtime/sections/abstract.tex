We introduce a graph-native runtime in which persistent truth, operational memory, resource pressure, and agent control are represented inside a single auditable substrate. The system separates an append-only \truthgraph{} from a dynamically compressed \viewgraph{}, models decision-making entities as presences with needs and masks, and routes probabilistic message packets called daimoi through a topology shaped by semantic affinity, congestion, and local scarcity. This coupling allows semantics to influence graph structure and routing cost directly, while resource pressure feeds back into behavior through local pricing and gravity-like demand fields. The core claim is not just improved retrieval, but a tighter unification of memory, control, and auditability than conventional retrieval-augmented generation pipelines and graph indexes provide.
